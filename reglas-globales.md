# Reglas globales — Humor Argentino Content Lab

## Objetivo
Crear, medir y mejorar contenido corto de humor argentino para TikTok usando evidencia real de @humor.argentino97.

## Reglas de producción
- Priorizar situaciones argentinas reconocibles, realismo y comprensión inmediata.
- Foto/video real + audio es una línea creativa de primera clase.
- Gemini se usa cuando aporta valor; no generar por generar.
- Prompts de video: una escena, una acción principal, preferencia 7–8 s, sin texto/voz generados salvo necesidad.
- Evitar física compleja, lateralidad delicada, manos/mecanismos difíciles y continuidad innecesaria.
- Máximo 2 intentos de generación por concepto. Si falla dos veces, se descarta.
- No publicar una tanda completa automáticamente: validar y espaciar para poder medir.
- Separar alcance, afinidad e intención de compartir; no evaluar solo por views.
- TikTok directo tiene prioridad para pulso inmediato cuando Metricool esté atrasado.
- No mezclar Pimpollito ni otros proyectos.

## Principio
Medir → aprender → crear → corregir → validar → generar/publicar → volver a medir.


## Stock visual persistente
Main es la línea de IMÁGENES. Cuando una propuesta visual sea validada, generar la imagen final y almacenarla en Biblioteca; no considerar terminado el stock si existe solamente el prompt. El branch experimental mantiene la línea de VIDEO.
